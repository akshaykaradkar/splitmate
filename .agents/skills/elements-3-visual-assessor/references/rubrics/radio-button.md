# Radio Button - Elements GM3 Rubric

1.  [ID: radio_button_circular_shape] Do the outer container and selected inner
    dot appear perfectly circular (Full shape style)? [Metric type: Hygiene] [Weight: 3]

2.  [ID: radio_button_group_exclusivity] Are selections within the same logical
    group mutually exclusive (only one selected)? [Metric type: Hygiene] [Weight: 3]

3.  [ID: radio_button_default_selection] Is a default option selected within the
    radio button group to prevent illegal empty states and establish clear user
    expectations? [Metric type: Adherence] [Weight: 3]

4.  [ID: radio_button_has_adjacent_label] Is every radio button paired with a clear,
    sentence-case text label that uses the "on-surface" color? [Metric type: Hygiene] [Weight: 3]

5.  [ID: radio_button_no_drop_shadows] Do radio buttons stay flat without drop
    shadows (resting at Elevation 0)? [Metric type: Hygiene] [Weight: 3]
