# Loading Indicator - Elements GM3 Rubric

1.  [ID: loading_indicator_mandatory_elements] Are mandatory elements present
    (spinner or linear progress track)? [Metric type: Hygiene] [Weight: 3]

2.  [ID: loading_indicator_continuous_animation] Does the loading indicator
    animate continuously? [Metric type: Hygiene] [Weight: 3]

3.  [ID: loading_indicator_track_ends_rounded] Are track ends cleanly rounded?
    [Metric type: Hygiene] [Weight: 3]

4.  [ID: loading_indicator_no_wavy_or_expressive] Is the loading indicator free of
    decorative GM3 Expressive / wavy waves, maintaining standard flat tracks or arcs?
    [Metric type: Adherence] [Weight: 5]

5.  [ID: loading_indicator_no_drop_shadows] Do loading indicators remain flat
    without drop shadows (resting at Elevation 0)? [Metric type: Hygiene] [Weight: 3]
