# Card

1.  [ID: card_purpose] Are cards used to display content and actions about a
    single subject in a flexible container, and not used as the default option
    when a simple list or no container would be more appropriate? [Metric type: Hygiene] [Weight: 5]

2.  [ID: card_container_rounded_corners] If a Card component (Elevated, Filled,
    Outlined, or Extended Filled) is present, does its container comply with the
    Elements GM3 specification: corner radius of 12dp (Medium baseline shape style)
    applied to all four corners? [Metric type: Hygiene] [Weight: 10]

3.  [ID: card_text_image_scrim] Is text layered over images only if there is a
    scrim or protection guaranteeing legibility? [Metric type: Hygiene] [Weight: 5]

4.  [ID: card_elevated_elevation] Do elevated cards use a drop shadow representing
    resting elevation level +2 (3dp height)? [Metric type: Hygiene] [Weight: 3]

5.  [ID: card_action_stacking] Are directly actionable cards free of independent
    nested interactive buttons or links to avoid action stacking? [Metric type: Hygiene] [Weight: 8]

6.  [ID: card_selection_style] If the card is used as a selection control, does it
    rely strictly on the checked/unchecked state of the nested radio button or checkbox
    to indicate selection, with no additional styles or colors applied to the card container
    for its selected state? [Metric type: Hygiene] [Weight: 5]

7.  [ID: card_focus_indicator] Do directly actionable cards feature a clear and perceivable
    focus indicator (focus ring) on keyboard focus to ensure compliance with Non-Text
    Contrast (NTC) requirements? [Metric type: Hygiene] [Weight: 5]
