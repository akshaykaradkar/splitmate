# Search - Elements GM3 Rubric

1.  [ID: search_container_rounded_corners] If a Search Bar container is present,
    does it comply with the specification: container height of 56dp and a fully
    rounded pill corner radius of 28dp (Full baseline shape style)?
    [Metric type: Hygiene] [Weight: 10]

2.  [ID: search_hint_text_contains_search] Does the search container contain
    clear, descriptive hint text that includes the word "Search" (e.g., "Search",
    "Search rooms")? [Metric type: Hygiene] [Weight: 3]

3.  [ID: search_max_two_trailing_icons] Does the search container contain at
    most 2 trailing icon buttons (excluding any user profile avatars)?
    [Metric type: Hygiene] [Weight: 3]

4.  [ID: search_clear_icon_button] When text is typed inside the search bar,
    does a clear text "x" icon button display immediately trailing the active text?
    [Metric type: Hygiene] [Weight: 3]

5.  [ID: search_corpus_selector_default_all] If a corpus selector is present,
    is its default scope set to "all" (or "All [items]") to prevent users from
    inadvertently narrowing their search results? [Metric type: Adherence] [Weight: 5]

6.  [ID: search_autosuggest_max_items] If auto-suggest is present, is the dropdown list
    limited to a maximum of 8 items to avoid overwhelming users? [Metric type: Adherence] [Weight: 3]

7.  [ID: search_focus_order_alignment] Is the keyboard focus navigation order of items within
    the search bar aligned with their LTR visual order? [Metric type: Adherence] [Weight: 3]
