# Progress Indicator - Elements GM3 Rubric

1.  [ID: progress_indicator_completion_fill] Does the active indicator fill
    reflect the actual percentage of completion? [Metric type: Hygiene] [Weight: 3]

2.  [ID: progress_indicator_rounded_ends] Do the progress indicator track and
    active indicators have cleanly rounded ends? [Metric type: Hygiene] [Weight: 3]

3.  [ID: progress_indicator_end_stop_dot] For linear determinate progress tracks,
    is there a mandatory 4dp circular end stop indicator (terminus dot) present at
    the trailing tip of the active track to ensure non-text contrast (NTC) accessibility?
    [Metric type: Adherence] [Weight: 5]

4.  [ID: progress_indicator_no_wavy_or_expressive] Is the progress indicator free of
    GM3 Expressive / wavy sine-wave patterns and decorative elements, maintaining a standard
    flat horizontal track or circular arc? [Metric type: Adherence] [Weight: 5]

5.  [ID: progress_indicator_no_drop_shadows] Do progress indicators stay flat
    without drop shadows (resting at Elevation 0)? [Metric type: Hygiene] [Weight: 3]
