# Grounded Synthesis Playbook (gthink)

> **Composes**: [`synthesize.md`](/labs/ix/gthink/core/references/synthesize.md)

This playbook defines `gthink`-specific caching invariants and tool output
verifications for Stage 4 (Synthesize). Universal synthesis principles
(epistemic supremacy, gap disclosures, zero numerical hallucination, active
hyperlinking, and references indexing) are inherited directly from
`synthesize.md`.

## Skill-Specific Cache & Tool Grounding

### 1. Cache-Backed Verification (`.gthink_cache/content/`)

-   **Document Headings Verification**: When citing a section in a Google Doc or
    PRD, verify that the heading exists in the ingested `headings` array in
    `.gthink_cache/content/doc_<id>.json` before referencing it.
-   **Affected Files Verification**: When asserting that a CL modified a
    specific subsystem or source file, confirm that the file path is present in
    `affected_files` in `.gthink_cache/content/cl_<num>.json`.
-   **Raw Text Support**: Every claim drafted in `.gthink_cache/draft.md` or the
    final report must trace directly to raw source text cached in
    `.gthink_cache/content/` (retrieved in Stage 3).

### 2. Verified Tool Output Attribution

-   **CL Authorship**: Only attribute CL author credit when verified by
    `analyze_cls` (tagged `(✅ VERIFIED AUTHOR)` in tool output). Never assume
    authorship from reviewer or CC lists.
-   **Task & Issue Status**: Cross-reference Buganizer and Taskflow states
    against outputs generated by `analyze_tasks`.
