# Tabs

1.  [ID: tabs_usage] Are tabs used for separating highly related content
    categories, rather than sequential workflow steps? [Metric type: Hygiene] [Weight: 5]

2.  [ID: tabs_active_indicator_line_position] Is the active indicator line
    positioned directly below the active tab label? [Metric type: Hygiene]
    [Weight: 3]

3.  [ID: tabs_labels_single_line] Are tab labels presented on a single line
    without wrapping? [Metric type: Hygiene] [Weight: 3]

4.  [ID: tabs_active_indicator_styling] Does the active indicator line have the correct thickness (3dp for Primary tabs, 2dp for Secondary tabs) and is it colored with `--droid-sys-color-primary`? [Metric type: Adherence] [Weight: 5]

5.  [ID: tabs_typography] Do tab labels use the font family `'Google Sans Text'` matching either `--droid-sys-typescale-title-small` or `--droid-sys-typescale-label-large`? [Metric type: Adherence] [Weight: 5]

6.  [ID: tabs_colors] Are active tab items styled with `--droid-sys-color-primary` and inactive tab items styled with `--droid-sys-color-on-surface-variant`? [Metric type: Adherence] [Weight: 5]

7.  [ID: tabs_container_height] Do the tab containers comply with the height specifications (47dp for label-only, 63dp for icon + label)? [Metric type: Adherence] [Weight: 3]

8.  [ID: tabs_bottom_divider] Is there a full-width bottom divider of 1dp using `--droid-sys-color-outline` or `--droid-sys-color-surface-variant`? [Metric type: Adherence] [Weight: 3]
