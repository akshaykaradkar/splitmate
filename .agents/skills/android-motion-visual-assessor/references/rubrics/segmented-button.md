# Segmented Button

1.  [ID: segmented_button_usage] Are segmented buttons used to toggle between
    complementary views (e.g., Day/Week/Month)? [Metric type: Hygiene] [Weight: 3]

2.  [ID: segmented_button_inner_segments_dividers] Are the inner segments
    separated by clean internal dividing lines of 1dp using --droid-sys-color-outline (light-dark(#747775, #8e918f))? [Metric type: Hygiene] [Weight: 3]

3.  [ID: segmented_button_content_centered] Are all text labels (using 'Google Sans Text')
    and associated icons centered perfectly within their segment? [Metric type: Hygiene] [Weight: 1]

4.  [ID: segmented_button_no_drop_shadow] Does the container stay flat without a
    drop shadow for elevation (complying with --droid-sys-elevation-level0)? [Metric type: Hygiene] [Weight: 3]
