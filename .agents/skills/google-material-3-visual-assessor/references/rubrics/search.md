# Search

1.  [ID: search_container_rounded_corners] If a Search Bar container is present,
    does it comply with the specification: container height of 56dp and a fully
    rounded pill corner radius of 28dp (represented by the `--md-sys-shape-corner-full` /
    `md.sys.shape.corner.full` design token)? [Metric type: Hygiene] [Weight: 10]

2.  [ID: search_hint_text_contains_search] Does the search container contain
    clear start-aligned hint text that includes the word "Search" (e.g., "Search your messages")? [Metric type: Hygiene]
    [Weight: 3]

3.  [ID: search_max_two_trailing_icons] Does the search container contain at
    most 2 trailing icon buttons (excluding a profile avatar, if present)? [Metric type: Hygiene] [Weight: 3]

4.  [ID: search_clear_icon_button] When text is typed, does a clear text "x"
    icon button display trailing the user input text to allow dismissal? [Metric type: Hygiene] [Weight: 3]
