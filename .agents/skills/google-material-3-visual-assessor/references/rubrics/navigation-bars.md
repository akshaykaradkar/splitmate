# Navigation Bars

1.  [ID: nav_bars_bottom_location] Is the "Navigation bar" component located at the very bottom of the screen? [Metric type: Adherence] [Weight: 3]

2.  [ID: nav_bars_active_pill] If a Navigation Bar active destination indicator is present, does it comply with the specification: height 32dp, width 64dp, corner radius 16px / pill (`--md-sys-shape-corner-full` or `--md-sys-shape-corner-large`), filled with `--md-sys-color-secondary-container`? [Metric type: Adherence] [Weight: 10]

3.  [ID: nav_bars_to_items] Are there between 3-5 items in the navigation bar? [Metric type: Adherence] [Weight: 3]

4.  [ID: nav_bars_label_present] Is there a label present for each navigation icon? [Metric type: Adherence] [Weight: 3]

5.  [ID: nav_bars_label_below_icon] For compact window sizes (e.g. mobile portrait), is there a label, and is it placed below the icon? [Metric type: Hygiene] [Weight: 3]

6.  [ID: nav_bars_label_trailing] For medium and larger window sizes (re: not mobile portrait), is the label trailing the icon (e.g. right of the icon in LTR languages, utilizing the GM3 Expressive horizontal navigation item configuration)? [Metric type: Adherence] [Weight: 3]
