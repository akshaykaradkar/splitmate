# Progress Indicator

1.  [ID: progress_indicator_completion_fill] Does the active indicator fill reflect the actual percentage of completion (for determinate states)? [Metric type: Hygiene] [Weight: 3]

2.  [ID: progress_indicator_rounded_ends] Do the progress indicator track and active indicators have cleanly rounded ends (complying with the GM3 shape specifications)? [Metric type: Hygiene] [Weight: 3]

3.  [ID: progress_indicator_no_drop_shadows] Do progress indicators stay flat without drop shadows? [Metric type: Hygiene] [Weight: 3]

4.  [ID: progress_indicator_stop_indicator] For determinate linear progress indicators, is a 4dp circular end stop indicator present at the trailing tip (mandatory if the inactive track contrast against its container or background is less than 3:1)? [Metric type: Adherence] [Weight: 10]

5.  [ID: progress_indicator_min_width] If a linear progress indicator is used, is its width at least 40dp? [Metric type: Adherence] [Weight: 3]

6.  [ID: progress_indicator_button_integration] If a circular progress indicator is embedded inside a button, is the inactive track removed, and does the active indicator use the same color role as the button's icon or label text to ensure at least a 3:1 contrast ratio? [Metric type: Adherence] [Weight: 5]

7.  [ID: progress_indicator_rtl_mirroring] For right-to-left (RTL) languages, is the linear progress indicator mirrored horizontally? [Metric type: Adherence] [Weight: 3]
