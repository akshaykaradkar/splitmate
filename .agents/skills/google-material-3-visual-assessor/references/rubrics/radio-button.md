# Radio Button

1.  [ID: radio_button_circular_shape] Do the outer container and selected inner
    dot appear perfectly circular, adhering to the `--md-sys-shape-corner-full` specification? [Metric type: Hygiene] [Weight: 3]

2.  [ID: radio_button_group_exclusivity] Are selections within the same logical
    group mutually exclusive, allowing only one active option? [Metric type: Hygiene] [Weight: 3]

3.  [ID: radio_button_no_drop_shadows] Do radio buttons stay flat without drop
    shadows, matching the `--md-sys-elevation-level0` standard? [Metric type: Hygiene] [Weight: 3]
