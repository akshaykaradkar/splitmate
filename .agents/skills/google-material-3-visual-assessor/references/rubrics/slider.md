# Slider

1.  [ID: slider_active_inactive_contrast] Does the active track segment clearly contrast with the inactive segment? [Metric type: Hygiene] [Weight: 3]

2.  [ID: slider_range_sliders_horizontal] Are range sliders (having two handles) oriented horizontally rather than vertically? [Metric type: Hygiene] [Weight: 3]

3.  [ID: slider_immediate_effect] Do adjustments to the slider take effect immediately without requiring a separate "Save" or confirmation button? [Metric type: Hygiene] [Weight: 3]

4.  [ID: slider_track_height_matches] Are the active and inactive sections of the track identical in height and layout structure? [Metric type: Hygiene] [Weight: 3]

5.  [ID: slider_contrast_anchoring] Does the trailing end of the inactive track feature a visual anchor (such as a stop indicator, icon, or label) ensuring at least a 3:1 contrast ratio against the background? [Metric type: Adherence] [Weight: 3]

6.  [ID: slider_inset_icon_usage] If inset icons are present inside the track, are they restricted only to standard (single-handle, non-centered) sliders of Medium (M), Large (L), or Extra Large (XL) size? [Metric type: Adherence] [Weight: 3]

7.  [ID: slider_track_shape_corner_radius] If standard MD3 sizing is used, does the track's corner radius match its size class specification (8dp for XS/S, 12dp for M, 16dp for L, 28dp for XL) using standard shape tokens (small, medium, large, extra large)? [Metric type: Adherence] [Weight: 5]

8.  [ID: slider_handle_shape_full] Does the slider handle utilize a fully rounded corner shape (`--md-sys-shape-corner-full`)? [Metric type: Hygiene] [Weight: 1]
