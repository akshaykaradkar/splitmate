# Date Picker

1.  [ID: date_picker_purpose] Is the date picker variant appropriately chosen (e.g., calendar grid for near dates, direct text entry modal/docked picker for distant dates like Date of Birth)? [Metric type: Hygiene] [Weight: 3]

2.  [ID: date_picker_modal_corner_radius] Do modal date pickers use a rounded rectangle container with a 28px corner radius (`--md-sys-shape-corner-extra-large` / 28px)? [Metric type: Adherence] [Weight: 3]

3.  [ID: date_picker_keyboard_toggle_icon] Does the component provide an accessible edit/calendar toggle icon to switch seamlessly between visual calendar grid mode and manual text input? [Metric type: Hygiene] [Weight: 3]

4.  [ID: date_picker_selected_day_circle] Is the selected day indicator represented as a solid filled circle (`--md-sys-shape-corner-full`) using the primary color role (`--md-sys-color-primary`) with the day label in `--md-sys-color-on-primary`? [Metric type: Adherence] [Weight: 3]
