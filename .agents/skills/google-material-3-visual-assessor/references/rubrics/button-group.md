# Button Group Rubric

1.  [ID: button_group_usage] Are related controls grouped together horizontally to establish a clear functional context (e.g. Back/Pause/Next, or single/multi-select options) instead of wrapping or being randomly scattered? [Metric type: Adherence] [Weight: 5]

2.  [ID: button_group_mandatory_elements] Are there two or more buttons or icon buttons in the group? [Metric type: Hygiene] [Weight: 3]

3.  [ID: button_group_member_size_uniform] Are all member buttons in the button group configured to the same size (XS, S, M, L, or XL) and shape configuration to maintain structural consistency, rather than mixing sizes? [Metric type: Hygiene] [Weight: 3]

4.  [ID: button_group_spacing] Do standard button groups maintain clear, consistent spacing between adjacent buttons (or, if it is a connected button group, are buttons joined with a consistent `--md-sys-measurement-space25` / 2px padding)? [Metric type: Hygiene] [Weight: 3]
