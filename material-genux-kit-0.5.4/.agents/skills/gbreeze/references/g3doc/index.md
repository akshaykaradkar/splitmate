gBreeze is a scalable and flexible web library for Material Design styles and
components. It is designed for use in AI-generated prototypes
(go/material-genux-kit).

gBreeze is a labs project within Material Web Components (go/mwc).

See the [quickstart guide](quickstart.md) for installation, setup, and usage
steps.

## Core concepts

The core philosophy of gBreeze is centered on **web standards** and **composable
layers** to achieve scalability and flexibility.

  * Stylesheets define Material tokens as custom properties.
  * Token CSS utility classes are generated by Tailwind.
  * Custom elements power components that work everywhere.
  * Component classes can be applied to custom HTML.
  * All styles use `@layer` and `::part()` to support overriding them.
